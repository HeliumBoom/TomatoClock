# 番茄钟桌面软件设计

在现有 .NET 8 WinForms 工程中实现 Windows 番茄钟，方便用户在工作时查看剩余时间，按工作与休息时长自动循环。窗口可缩放，可随时切换置顶，缩小时可仅显示时间。第一版沿用现有技术，不增加第三方运行库。

本设计纳入需求讨论中确认的八项决定：休眠暂停、无标题栏紧凑显示、修改时长下轮生效、声音默认关闭、单实例、拖动时间移动窗口、右键菜单与双击恢复入口，以及用颜色和暂停符号表达紧凑模式状态。

## 功能与界面

- 普通模式使用标准 Windows 窗体边框，允许拖动、缩放、最大化和最小化。界面使用中文，从上到下显示当前阶段、大号剩余时间、阶段进度、开始或暂停按钮、重置按钮和设置入口。
- 时长、始终置顶、声音提醒和隐藏任务栏图标放在设置面板，普通模式与紧凑模式均能打开。打开设置面板不暂停计时；设置入口不重建计时模型。
- 工作时长默认 25 分钟，休息时长默认 5 分钟；分别允许设置 1～180 的整数分钟，通过数字输入控件限制非法输入。
- 切换置顶后立即应用到当前窗口。置顶指普通桌面窗口的置顶层级，不承诺覆盖系统安全桌面等特殊界面。
- “声音提醒”默认关闭，切换后立即生效并记住状态。仅在开启时，阶段结束播放一次系统提示音。声音是补充反馈，不弹出需要确认的对话框，不抢占输入焦点。
- 工作使用暖色，休息使用绿色，普通模式同时显示阶段文字。暂停时数字降低亮度，但保持可读对比度，并显示不可点击的小暂停符号。

## 紧凑模式与操作入口

紧凑模式隐藏标题栏、阶段文字、进度和全部按钮，仅保留倒计时以及暂停时的小暂停符号。鼠标悬停显示“工作／休息 · 运行中／已暂停／待开始”等状态文字。待开始与暂停在模型中保持区分。

| 操作 | 行为 |
| --- | --- |
| 拖动时间区域 | 移动窗口，不切换计时状态 |
| 拖动窗口边缘或角落 | 调整大小，倒计时字体随空间变化 |
| 单击时间 | 不改变计时状态 |
| 双击时间 | 恢复普通窗口，不改变计时状态 |
| 右键 | 打开菜单：开始／暂停／继续、重置、时长设置、始终置顶、声音提醒、恢复普通窗口和退出 |
| 窗口获得焦点时按空格 | 在开始、暂停和继续之间执行对应操作；编辑时长或操作设置控件时不截获空格 |

菜单项的名称和勾选状态与当前状态同步。紧凑模式下打开设置后，设置面板不能被置顶的计时窗口遮挡。关闭设置面板不关闭计时窗口。

初版采用以下布局参数，均为 96 DPI 下的逻辑客户区尺寸，按系统缩放比例换算：

- 默认普通窗口 400 × 420，最小客户区 120 × 64。
- 普通模式下，宽度小于 320 或高度小于 240 时进入紧凑模式。
- 紧凑模式下，宽度达到 360 且高度达到 280 时恢复普通模式。进入和退出阈值错开，防止边框变化导致模式反复切换。
- 双击或菜单恢复普通窗口时，使用上次满足普通模式恢复阈值的尺寸；没有有效记录则使用默认尺寸。
- 缩放模式切换保持窗口位置尽量稳定，不重置计时，不改变置顶状态。移除标题栏后仍必须支持边缘和角落缩放。
- 最大化窗口使用普通模式；最小化不触发模式切换或覆盖已保存尺寸。重新打开时恢复退出前的普通或紧凑模式及其非最小化、非最大化尺寸。

这些尺寸是初版实现参数，验收时同时检查最小尺寸下最长的倒计时、暂停符号和高 DPI 显示是否完整可见。

## 计时规则

一个周期由工作和休息两个阶段组成，顺序为“工作 → 休息 → 工作”，持续循环，直到用户暂停或关闭程序。

| 操作或事件 | 结果 |
| --- | --- |
| 首次启动或重新打开程序 | 进入工作待开始状态，展示设置的完整工作时长，不自动计时 |
| 点击开始 | 从显示的剩余时间开始计时 |
| 点击暂停 | 保留当前阶段及精确剩余时间，暂停期间不消耗时间 |
| 点击继续 | 从暂停的位置继续 |
| 点击重置 | 停止计时，回到工作待开始状态，采用最新工作时长 |
| 工作到时 | 自动进入休息，采用此时的休息时长设置 |
| 休息到时 | 自动进入工作，采用此时的工作时长设置 |
| 在计时中或暂停时修改时长 | 当前阶段的总时长及剩余时间不变；后续阶段进入时使用新设置 |
| 在待开始状态修改工作时长 | 立即刷新工作倒计时 |
| 最小化或锁屏 | 继续计时；阶段切换不恢复窗口、不抢焦点 |
| 系统进入睡眠或休眠 | 如果正在运行，记录当前阶段及精确剩余时间，转为暂停 |
| 系统唤醒 | 保持暂停，等待用户手动继续；不补算睡眠或休眠期间的周期，不补播提示音 |
| 退出程序 | 保存设置，不保存本轮计时进度；托盘模式下点击窗口关闭仅收起窗口 |

原本已暂停或待开始时，睡眠、休眠与唤醒不改变其状态。若锁屏后系统进一步进入睡眠，按睡眠规则暂停。

修改运行中或暂停时的时长后，明确显示“下次工作开始时生效”或“下次休息开始时生效”。当前倒计时和进度始终基于进入本阶段时记录的时长；重置立即采用最新工作时长。例如工作 25 分钟已过去 10 分钟，将工作时长改为 15 分钟，本轮仍剩余 15 分钟，本轮进度仍为 10/25，下轮工作才使用 15 分钟。

计时逻辑根据运行期间实际经过的时间计算剩余量，不以界面定时器触发次数减秒。使用单调时钟避免修改系统时间影响倒计时；显式处理系统挂起和恢复事件，排除睡眠、休眠和手动暂停的时间。

显示剩余秒数向上取整，避免阶段尚未结束时提前显示零。时间格式为总分钟和两位秒数，例如 25:00、05:00、180:00。正常运行中一次界面更新跨过多个阶段时，消耗完整的运行经过时间并恢复到正确阶段；声音开启时合并提示为一次。该补算规则不适用于睡眠或休眠期间。

## 单实例与退出

同一个 Windows 用户会话只允许一个程序实例。再次启动时请求已有实例显示窗口；已有窗口最小化时恢复，紧凑模式保持紧凑。此次显式启动可以激活已有窗口，但不得重置计时、重新加载设置或改变置顶选项。

托盘模式关闭时，普通窗口关闭按钮和菜单退出均结束程序。下次启动读取设置并进入工作待开始状态，不恢复本轮进度。

## 托盘模式

用户追加要求支持不显示任务栏按钮、仅保留通知区域图标。新增“隐藏任务栏图标（使用托盘）”设置，默认关闭，修改后即时应用并持久化。

- 开启后任务栏按钮隐藏，计时窗口和设置窗口不出现在 Alt+Tab 列表，托盘图标显示；桌面计时窗口保持当前普通或紧凑形态，不重置或暂停计时。关闭托盘模式后恢复正常窗口切换行为。
- 开启时最小化或点击关闭仅将窗口收起到托盘，后台继续计时。设置面板随收起关闭，避免出现无法找回的独立窗口。
- 托盘双击和“显示窗口”菜单恢复当前计时窗口；再次启动程序同样可找回窗口。恢复不改变托盘模式、时长和计时状态。
- 托盘右键与窗口右键共用计时操作，提供显示窗口、收起到托盘、开关托盘模式及退出。菜单状态与真实窗口状态同步。
- “退出”始终结束程序并清理托盘图标。系统关机或应用退出不被收起规则拦截。
- 关闭托盘模式时，恢复任务栏按钮；如果窗口已隐藏或最小化，先恢复可操作窗口，再移除托盘图标。
- 开启托盘模式后下次启动仍显示计时窗口，但不显示任务栏按钮；不恢复上次隐藏状态，也不自动开始计时。
- 托盘悬停文字显示当前阶段、剩余时间和运行状态；图标使用已生成的番茄钟图标。Windows 可按用户系统设置将图标放入折叠区域。
- Alt+Tab 排除采用 WS_EX_TOOLWINDOW 并移除 WS_EX_APPWINDOW，按 [Microsoft 扩展窗口样式规则](https://learn.microsoft.com/en-us/windows/win32/winmsg/extended-window-styles) 实现。窗口句柄重建后仍保留规则；仅因鼠标穿透显示托盘图标时，不改变 Alt+Tab 显示偏好。

## 模块与数据

### 窗口透明度与鼠标穿透

用户追加要求调整窗口透明度及是否穿透窗口。设置面板提供“不透明度”滑块，范围 10%～100%，默认 100%；数值越低越透明，至少保留 10% 可见程度。主计时窗口即时应用，设置面板保持完全不透明。

“鼠标穿透计时窗口”默认关闭，可从设置及托盘菜单切换。开启后整个计时窗口的鼠标操作传递给后面的应用，原有拖动、缩放及直接点击按钮暂不可用；计时不受影响。通过托盘菜单取消穿透后恢复正常操作。

只要鼠标穿透或托盘模式有一项开启，就显示托盘图标，保证恢复入口。鼠标穿透不强制改变任务栏按钮的显示偏好。两项都关闭时才移除托盘图标。重启恢复不透明度和鼠标穿透设置；托盘菜单仍可打开设置或退出。

实现采用 Windows 分层窗口与 WS_EX_TRANSPARENT，支持穿透到其他进程的窗口；不是仅返回同线程命中测试的 HTTRANSPARENT。依据 [Microsoft 分层窗口命中规则](https://learn.microsoft.com/en-us/windows/win32/winmsg/window-features)。普通／紧凑布局切换和任务栏引发的窗口句柄重建必须保留效果，完全不透明时仍支持鼠标穿透。

### 职责分工

- **计时模型**：管理工作和休息阶段、待开始和运行及暂停状态、阶段时长快照、剩余时间和阶段切换。提供开始、暂停、重置、更新设置和推进时间的接口，不引用 WinForms 控件。经过时间由调用方传入，便于直接验证边界。
- **窗体与设置面板**：构建普通和紧凑布局，处理缩放、拖动、菜单、键盘操作和设置修改；使用单调时钟测量经过时间，使用 UI 定时器刷新显示。根据模型状态更新界面和提示音。
- **生命周期与单实例入口**：在创建主窗体前决定实例身份，将再次启动请求转交已有窗体；订阅系统挂起和恢复事件，并将状态转换送至 UI 线程。退出时释放订阅和实例资源。
- **设置存储**：将工作时长、休息时长、置顶状态、声音开关、托盘模式、显示模式、当前还原尺寸与上次普通模式尺寸存入当前用户的本地应用数据目录。窗口尺寸排除最小化和最大化状态。

计时模型是计时状态的唯一来源，窗体不维护第二套剩余时间。缩放、置顶和设置保存都不重启计时，也不改变当前阶段。

## 设置与异常处理

设置文件缺失时使用默认值：工作 25 分钟、休息 5 分钟、声音关闭、置顶关闭、普通模式。文件无法解析时使用整套默认值；单个字段缺失或超出范围时仅回退该字段，保留其他有效设置。

恢复的窗口尺寸限制在当前屏幕工作区内，并满足紧凑界面最小尺寸；启动位置保持在可见工作区内。按调整后的可用尺寸确定显示模式，不能为了保留普通模式而让操作入口移出屏幕。

设置改变后保存，窗口尺寸在调整结束后保存，退出前再次保存。写文件采用临时文件替换方式，降低中断写入破坏已有设置的风险。

设置写入失败时，当前会话继续可用，在设置面板显示简短的非阻塞提示，不阻止退出。退出时停止并释放定时器、系统事件订阅、托盘图标和界面资源。第一版不包括开机启动、历史统计、账户同步或长休息规则。

## 验收

1. 编译现有解决方案，保持 net8.0-windows 目标框架。
2. 验证计时模型：开始、暂停期间时间不变、继续、重置、阶段边界、跨多个阶段的时间推进，以及运行或暂停时修改时长。
3. 启动真实窗体，验证普通与紧凑模式的双向尺寸切换，阈值附近不能反复抖动；在 100%、150%、200% 系统缩放下，最小尺寸仍能完整显示 180:00 和暂停符号。
4. 验证无标题栏时拖动时间可移动、边缘和角落可缩放、双击恢复普通窗口、右键可完成全部操作；单击或拖动不能误触暂停。编辑时长时空格键不切换计时。
5. 验证工作和休息配色、暂停符号、悬停状态、时长下轮生效提示、当前阶段进度和自动切换；时长控件拒绝 0、负数及超过 180 的值。
6. 验证最小化和锁屏继续计时；运行中睡眠或休眠后唤醒保持原阶段的剩余时间并暂停，手动继续后才推进；原本暂停或待开始时唤醒保持原状态。修改系统时间不改变倒计时。
7. 验证声音默认关闭、开启后仅在阶段切换提示、关闭后立即停止后续声音提醒；阶段切换不抢焦点。置顶开关即时生效，紧凑模式的设置面板可正常操作。
8. 验证再次启动只显示已有实例，计时不重置；最小化后再次启动可恢复；退出后可以重新启动。
9. 检查重启后恢复时长、声音、置顶、显示模式和窗口尺寸，同时保持待开始状态；检查损坏文件、单字段无效和保存失败的回退行为。
10. 自动化模型验证与实际桌面交互验收分别报告；未实际执行的桌面检查保持待验收状态。
11. 验证托盘开关实时与重启生效、收起后继续计时、最小化及关闭不退出、恢复窗口不重置计时、退出清理图标、关闭托盘模式后不丢失窗口，以及不拦截系统关机。
12. 验证透明度实时与重启生效、非法数值回退、不影响设置面板；验证穿透时跨进程命中后方窗口、关闭后恢复自身命中，并检查完全不透明、边框切换、任务栏切换及托盘恢复入口。
