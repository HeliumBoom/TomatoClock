# TomatoClock 番茄钟

Windows 桌面番茄钟，支持自动工作休息循环、可缩放窗口、紧凑悬浮显示和始终置顶。默认工作 25 分钟、休息 5 分钟，声音与置顶默认关闭。

## 启动与构建

当前支持透明度和鼠标穿透的版本位于 `dist-overlay/TomatoClock.exe`。新版使用独立目录；请先退出旧程序，再运行新版，否则单实例机制会激活旧程序。发布版本使用 .NET 8 Windows Desktop Runtime；此工程所在电脑已安装该运行时。分发给其他电脑时应复制整个发布目录。

使用 Visual Studio 打开 `TomatoClock.sln`，或在工程目录执行：

```powershell
dotnet run --project TomatoClock.csproj
dotnet build TomatoClock.sln -c Release
dotnet publish TomatoClock.csproj -c Release --no-restore --self-contained false -o dist
```

## 操作

- 普通窗口：开始、暂停或继续；重置回到工作待开始；设置中调整工作和休息时长（1～180 分钟）、置顶与声音。
- 缩小窗口自动进入紧凑模式，只显示时间；工作为暖色，休息为绿色，暂停时显示小暂停符号。
- 紧凑窗口：拖动时间移动，拖动边缘或角落缩放；双击恢复普通窗口；右键打开全部操作。
- 主窗口有焦点时按空格，执行开始、暂停或继续。
- 修改运行中或暂停时的时长，本轮保持不变，下次进入对应阶段才使用新时长；重置立即使用最新工作时长。
- 工作与休息到时自动交替。最小化、锁屏继续计时；睡眠或休眠后暂停，唤醒后需要手动继续。
- 设置中可开启“隐藏任务栏图标（使用托盘）”：立即移除任务栏按钮，同时将计时窗口和设置窗口从 Alt+Tab 列表中隐藏；右下角保留番茄钟托盘图标，桌面计时窗口仍可见。关闭该选项恢复正常窗口切换行为。
- 托盘模式下，最小化或点击窗口关闭会收起窗口并继续计时。双击托盘图标或选择“显示窗口”可找回；托盘右键菜单也可开始／暂停、重置、打开设置或退出。
- 需要完全结束程序时选择右键菜单“退出”。关闭托盘模式后恢复任务栏显示，窗口关闭按钮恢复直接退出。
- 设置中的“不透明度”滑块支持 10%～100%，100% 为完全可见，数值越低越透明，调整即时生效。
- 开启“鼠标穿透计时窗口”后，鼠标操作落到计时窗口后面的应用，不能再直接拖动或点击计时窗口。托盘图标会自动保留，可右键取消“鼠标穿透”，或从托盘打开设置。设置窗口始终保持完全可见、可操作。
- 鼠标穿透和隐藏任务栏图标是独立开关：关闭隐藏任务栏图标时，只要仍开启鼠标穿透，托盘入口就会保留。
- 再次启动会显示已有实例，包括已收起到托盘的窗口。下次启动等待手动开始。

设置保存在 `%LOCALAPPDATA%\TomatoClock\settings.json`。保存时长、声音、置顶、托盘模式、不透明度、鼠标穿透、显示模式和窗口尺寸，不保存本轮计时进度。默认不透明度为 100%，鼠标穿透和托盘模式关闭；开启托盘模式后再次启动会显示计时窗口，但不显示任务栏按钮。设置文件损坏时自动回退默认值。

托盘图标可能位于 Windows 右下角的折叠区域，可点击向上的箭头找到它。

## 验证

无外部测试包依赖的测试程序：

```powershell
dotnet run --project tests/TomatoClock.Tests
dotnet run --project tests/TomatoClock.Tests -- --artifacts artifacts/verification
```

测试覆盖真实计时模型、JSON 持久化、WinForms 控件操作、注入电源消息和跨进程单实例信号。生成的窗口渲染图在 `artifacts/verification`。

电源消息注入不等同于真实休眠验收。真实睡眠／休眠、锁屏、声音播放和多显示器 100%／150%／200% DPI 的操作体验仍需在桌面人工验证，测试不会自动使电脑休眠或锁屏。

完整行为规则见 `docs/superpowers/specs/2026-10-08-tomato-clock-design.md`。
